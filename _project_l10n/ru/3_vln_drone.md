## Обзор {#overview}

Создан надёжный конвейер генерации разнообразных трёхмерных навигационных траекторий в симуляторе Habitat для обучения политик навигации по визуальным и языковым указаниям (VLN) на воздушных роботах.

**Мотивация:** существующие датасеты VLN рассчитаны на наземных роботов и дискретные навигационные графы; дронам нужны непрерывные трёхмерные траектории взлёта → крейсерского полёта → посадки, а такого датасета не существовало, поэтому мы построили его с нуля.

**Симулятор:** Habitat с 90 внутренними сценами.

**Масштаб:** 90 сцен × 200–300 пар «старт — цель» в каждой → **10 000+** трёхэтапных 3D-траекторий с языковыми инструкциями, выложенных в открытый доступ на GitHub.

## Конвейер {#pipeline}

{% include svg_figure.liquid name="vln_pipeline" caption="Четырёхшаговый конвейер генерации. Lattice A* планирует по моторным примитивам в (x, y, θ), поэтому дрон поворачивает на ходу, а не делает прямоугольные повороты, как Grid A* (схема ниже, иллюстративная)." %}

1. **Генерация пар «старт — цель»** — Для каждой из 90 сцен генерируется 200–300 случайных 2D-пар «старт — цель» в качестве конечных точек навигации.

2. **Планирование 2D-пути крейсерского полёта** — Для каждой сцены подбирается подходящая постоянная крейсерская высота, затем на этой высоте планируется естественный 2D-путь с помощью **Lattice A\***. В отличие от стандартного Grid A\*, дающего жёсткие прямоугольные повороты, Lattice A\* планирует по моторным примитивам в непрерывном пространстве состояний $$(x, y, \theta)$$ и получает плавные пути, на которых агент поворачивает, продолжая двигаться вперёд. Эвристика:

   $$H(s) = \frac{\|p - p_{goal}\|}{L} + \lambda \cdot |\Delta\theta|$$

   Она штрафует резкие повороты, обеспечивая плавные и реалистичные траектории полёта.

3. **Сборка 3D-траектории** — К каждому крейсерскому пути спереди добавляется сегмент **взлёта**, а сзади — сегмент **посадки**, образуя полную 3D-траекторию. Вдоль всего пути RGB-D-наблюдения записываются как видео.

4. **Генерация инструкций** — Модель «видео → текст» создаёт навигационные инструкции на естественном языке по записанным видео наблюдений, в результате получается полноценный датасет VLN.

Конструкция намеренно упрощена — дрон не меняет высоту часто в полёте, — однако взлёт и посадка в сочетании с инструкциями уже сложны для современных моделей. Обучением политик на этом датасете занимаются коллеги по лаборатории.
